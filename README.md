Tic-Tac-Toe (Java)
A two-player console Tic-Tac-Toe game with selectable board size.
Run
javac TicTacToe.java
java TicTacToe
How to play
Choose a board size: 3x3, 5x5 or 6x6.
Players X and O take turns entering a cell number.
Win condition: 3 in a row on 3x3, 4 in a row on 5x5 and 6x6 (horizontal, vertical or diagonal).
